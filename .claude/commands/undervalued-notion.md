특정 지역의 저평가 아파트를 분석해서 노션에 Threads 게시용으로 공유한다.

## 인자
- $ARGUMENTS: 조건 조합 (예: "서울 8~12억", "분당구 20평대", "강남구 30평대 15억이상")
- 지역: 시도(서울, 경기) 또는 시군구(분당구, 강남구) — 없으면 "분당구"
- 평대: 20평대, 30평대 등 — 없으면 전체
- 가격대: "8~12억", "15억이상", "10억이하" 등 — 없으면 전체
- TOP 개수: "TOP3", "TOP5" 등 — 없으면 TOP 10

## 분석 기준
1. valuation 데이터에서 지역 필터 (sigungu 또는 시도 단위)
2. 평대가 있으면 전용면적 필터 (20평대 = 59~84m², 30평대 = 84~115m² 등)
3. 가격대가 있으면 current_price 필터 (만원 단위, 예: 8~12억 = 80000~120000)
4. 같은 apt_name 중복 제거 (첫 번째만 유지)
5. **3년 vs 3개월 차이 비교**:
   - 3년 차이 = (본인 avg_36 / 비교 compare_avg_36 - 1) × 100
   - 3개월 차이 = (본인 3개월평균 / 비교단지 3개월평균 - 1) × 100
   - 3개월 평균은 by_apt/{id}.json에서 최근 90일 거래 평균으로 직접 계산
   - 벌어짐 = 3개월차이 - 3년차이 → 음수 클수록 최근에 더 저평가
6. 벌어짐 순 정렬, TOP N 추출
7. 각 단지의 입지/교통 정보는 valuation_geo.json에서 조회

## 용어
- "괴리"라는 단어 사용 금지 → "차이"로 표기
- "벌어짐" = 3개월차이 - 3년차이

## 면적 표기
- 전용면적만 표기, 소숫점 없이 (int)
- 표기 형식: "{int(전용면적)}m²" ("전용" 단어 붙이지 않음)
- 평수 표기 없음

## 노션 출력 형식
- 부모 페이지 ID: 30c499fc-6e6d-8066-85be-ecbf98c12134 (하위 페이지로 생성)
- NOTION_API_KEY: .env 파일에서 읽기
- 페이지 제목: "{지역} 저평가 TOP{N} ({조건}) — {날짜}"
- 구성:
  1. heading_1: "Threads 게시용"
  2. code 블록: Threads 복붙용 텍스트 (최대 3파트)
  3. divider
  4. heading_1: "상세 데이터"
  5. 각 단지별: heading_2 + callout(3년차이/3개월차이/벌어짐/입지/교통/세대수) + 비교단지 bulleted_list

## Threads 글자수 제한
- Threads 한 게시물 최대 **500자**
- **최대 3파트**로 분할 (더 많이 나누지 않음)
- 각 파트를 별도 code 블록으로 노션에 작성
- 파트 구분: "[1/3]", "[2/3]", "[3/3]" 을 각 파트 끝에 표기
- 파트1: 인트로 + 1위 단지
- 파트2: 나머지 단지들
- 파트3: 설명 + aptmine.com
- 단지 정보는 단지 단위로 끊기 (중간에서 자르지 않기)

```

비교단지 대비 최근 3개월이 3년 평균보다 더 벌어진 단지
= 시장에서 상대적으로 못 올라온 아파트

1. {아파트명} ({시군구} {동}, {면적}m²)
   현재 {금액}억 · {지하철}({호선}) 도보{분}분 · 강남{분}분
   비교단지: {비교단지1}, {비교단지2}
   3년 {본인}억 vs {비교}억 (차이 {%}%)
   3개월 {본인}억 vs {비교}억 (차이 {%}%) → 벌어짐 {%}%p
[1/3]

[파트2]
2. {아파트명} ...
3. {아파트명} ...
[2/3]
```

## 매물호가 조회 (네이버 부동산)
- `scripts/fetch_naver_listings.py`를 subprocess로 호출
- 사용법: `python scripts/fetch_naver_listings.py '아파트명|시군구|동|면적' ...`
- 출력: JSON `[{min, max, count}, null, ...]`
- 6개씩 배치 분할 (timeout 방지)
- 호가 조회 후 비교단지 3개월평균과 비교:
  - 호가 < 비교단지평균 → ✓ 표시 (매수 기회)
  - 호가 >= 비교단지평균 → ✗ 표시
- 노션 출력 시: 호가 < 비교단지 아파트를 먼저 보여주고, 나머지도 아래에 전체 표시

## Threads 텍스트 형식 (매물호가 포함)
각 단지 항목 끝에 다음 2줄 추가:
```
   매물호가 {min}~{max}억({count}건)
   비교단지평균 {comp}억 → 호가보다 {diff}억 높음 ✓
```
호가 없는 경우 해당 줄 생략.

## 표기 규칙
- 전용면적 소숫점 없이 (int)
- 가격은 억 단위 소숫점 1자리
- 교통: 지하철역(호선) 도보N분 · 강남N분 형식
- callout에는 최근 거래 흐름도 포함 (최근 5건: X → X → X억)
- 면적은 반드시 m² (평 사용 금지)

## 데이터 경로
- valuation: docs/data/apt_trade/valuation/{시도}.json
- valuation_geo: docs/data/apt_trade/valuation_geo.json (입지/교통/세대수)
- apt_meta: docs/data/apt_trade/apt_meta.json (준공연도)
- by_apt: docs/data/apt_trade/by_apt/{id}.json (3개월평균 계산용, 최근거래 조회용)
- 시도 매핑: 분당구/수원시/성남시 등 → 경기.json, 강남구/서초구 등 → 서울.json, 해운대구 등 → 부산.json
- 호가 스크립트: scripts/fetch_naver_listings.py (DOM 스크래핑, Playwright)
